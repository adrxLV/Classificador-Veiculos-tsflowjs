# Classificador de Veículos (TensorFlow.js)

Um projeto frontend que demonstra um classificador de veículos executado no navegador com TensorFlow.js. Este repositório contém a interface (HTML/CSS) e os recursos necessários para testar um classificador de imagens de veículos diretamente no cliente. O modelo foi treinado com o Teachable Machine e exportado como tensorflowjs model.

## Recursos
- Interface simples para carregar imagens.
- Classificação de imagens de veículos com um modelo que roda no navegador (TensorFlow.js).
- Layout responsivo
